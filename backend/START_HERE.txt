🎯 WHAT IS THIS?
═══════════════════════════════════════════════════════════════════════════

This is a complete FastAPI backend for a visual pipeline builder that:
  • Executes pipelines with nodes (Input, Text, LLM, Output)
  • Connects nodes with edges in a directed graph
  • Runs them in the correct order (topological sort)
  • Integrates with OpenAI's API for LLM nodes
  • Returns results or meaningful error messages


🚀 QUICK START (3 COMMANDS)
═══════════════════════════════════════════════════════════════════════════

  1. pip3 install -r requirements.txt
  2. python3 -m uvicorn main:app --reload
  3. Open: http://localhost:8000/docs

That's it! Server is running and ready for API calls.

🔌 API ENDPOINTS
═══════════════════════════════════════════════════════════════════════════

GET /
  Health check
  Response: {"status": "ok"}

POST /pipelines/execute
  Execute a pipeline
  Input: {nodes: [...], edges: [...]}
  Output: {status: "success", results: {...}}


🎯 NODE TYPES (all supported)
═══════════════════════════════════════════════════════════════════════════

1. customInput
   Receives external data from the pipeline

2. text
   Processes text with {{variable}} interpolation

3. llm
   Calls OpenAI GPT API to generate text

4. customOutput
   Captures and returns pipeline results


🔧 CONFIGURATION
═══════════════════════════════════════════════════════════════════════════

Works without setup (development mode):
  • LLM nodes return mock responses
  • Perfect for testing
  • No API charges

To use real LLM:
  1. Get API key from https://platform.openai.com/api-keys
  2. Create .env file: echo "OPENAI_API_KEY=sk-..." > .env
  3. Restart server
